# Demo Images

These images were captured from a short simulation run of the UVM verification environment.

The purpose of this run was to demonstrate:
- End-to-end verification flow (APB → RX → Model → TX → Scoreboard)
- Monitor visibility and transaction tracing
- Scoreboard comparison between expected and actual results
- Functional coverage collection

Coverage values shown are intentionally based on a limited number of transactions
to keep the logs readable and focused for demonstration purposes.
